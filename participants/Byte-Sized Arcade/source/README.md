# 🚀 ФинКонтур

### Интеллектуальная система анализа бюджетных потоков

<p align="center">
  <b>Контроль. Анализ. Прозрачность.</b><br>
  Веб-инструмент для выявления финансовых рисков и управления бюджетом
</p>

## ✨ О проекте

**ФинКонтур** — это интерактивное аналитическое приложение, которое превращает сырые бюджетные данные в понятную картину:

* где деньги
* куда они идут
* где есть нарушения

Проект имитирует реальную систему финансового контроля уровня регионального Минфина.

## ⚡ Ключевые возможности

### 📊 Аналитика в реальном времени

* агрегирование данных по лимитам, обязательствам и кассе
* автоматический пересчёт показателей
* динамика за год

### 🧠 Умный контроль

* выявление превышений лимитов
* проверка бюджетной дисциплины
* подсветка аномалий

### 🔎 Гибкая фильтрация

* КЦСР / КВР
* бюджеты и получатели
* текстовый поиск
* голосовой ввод 🎤

### 🗺 Визуализация данных

* таблицы с детализацией
* карта финансовых потоков
* сценарный анализ

### 📤 Экспорт отчётов

* Excel
* PDF

## 🖥️ Интерфейс

> Минималистичный тёмный UI с акцентом на читаемость и плотность данных

* sticky-панель управления
* KPI-блоки
* табы (РЧБ, Соглашения, БУАУ, Контроль)
* интерактивные таблицы

## 🧩 Источники данных

| Источник   | Описание                |
| ---------- | ----------------------- |
| РЧБ        | Роспись + лимиты ПБС    |
| Соглашения | Планирование выплат     |
| БУАУ       | Кассовое исполнение     |
| ГЗ         | Государственные закупки |


## 🏗️ Стек технологий

* **Frontend:** HTML5, CSS3, Vanilla JS
* **Работа с данными:**

  * `xlsx` — Excel экспорт
  * `jsPDF` / `pdfmake` — PDF
  * `JSZip`

## 🎯 Как использовать

1. Выбери период (месяц или год)
2. Укажи источники данных
3. Примените фильтры
4. Нажми **«Сформировать отчёт»**
5. Анализируй или экспортируй результат
