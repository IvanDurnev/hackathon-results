# Презентум — Веб-генератор презентаций на ИИ

Полноценный веб-сайт для генерации PPTX/PDF презентаций с помощью LLM (Qwen 2.5) и Stable Diffusion / Яндекс ART.

## 📁 Структура проекта

```
prezentum/
├── app.py              ← Flask бэкенд
├── generator.py        ← Ваш rab_2.py (переименован)
├── requirements.txt    ← Зависимости
├── templates/
│   └── index.html      ← Фронтенд (всё в одном файле)
├── uploads/            ← Временные загруженные файлы
└── outputs/            ← Сгенерированные PPTX и PDF
```

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd prezentum
pip install -r requirements.txt
```

### 2. Настройка API-ключа

В файле `generator.py` найдите строку:
```python
TOKEN = "eyJhbGciOiJIUzM4..."
```
Замените на ваш актуальный токен от ai.rt.ru.

### 3. Запуск сервера

```bash
python app.py
```

Откройте в браузере: **http://localhost:5000**

## 🎨 Цветовые темы

- **Тёмная** — по умолчанию, глубокий синий фон
- **Светлая** — чистый белый
- **Океан** — тёмно-синий с голубым акцентом
- **Лес** — тёмно-зелёный
- **Закат** — тёмно-красный с оранжевым

## 🔧 Продакшн-запуск

Для запуска на сервере рекомендуется использовать Gunicorn:

```bash
pip install gunicorn
gunicorn -w 2 -b 0.0.0.0:5000 --timeout 600 app:app
```

**Важно**: увеличенный timeout (600 сек) нужен из-за длительной генерации изображений.

---

## 📝 Примечания

- Все задачи генерации выполняются в фоновых потоках — браузер не зависает
- Файлы презентаций хранятся в папке `outputs/`
- Загруженные документы сохраняются в `uploads/` (можно настроить автоочистку)
- API-токен хранится в `generator.py` — не публикуйте его в открытый доступ
