# Проект: Амур.Бюджет Конструктор
*Интеллектуальный конструктор аналитических выборок для Минфина Амурской области*

---

## 1. Анализ кейса
* **Суть:** Создание инструмента для автоматизированного сбора данных из систем «Планирование», «Финансы» и «Госзаказ».
* **Проблема:** Разрозненность данных и сложность ручного сопоставления по сквозным кодам (КЦСР, КВР, КБК).
* **Целевая аудитория:** Сотрудники Минфина, аналитики, руководители ведомств.
* **Ключевая идея:** Умный фильтр и визуальный конструктор, автоматизирующий "склейку" таблиц.

---

## 2. Предлагаемое решение (MVP)
### Основные функции
* **Умный фильтр:** Поиск по КЦСР, КВР и муниципальным образованиям (МО).
* **Автоматическая склейка:** Сопоставление лимитов (РЧБ) с выплатами (Финансы) по кодам.
* **Визуализация:** Авто-генерация графиков (план vs факт).
* **Экспорт:** Выгрузка готовой выборки в чистый Excel.

### Технологический стек
* **Frontend:** React + Vite, Tailwind CSS, Recharts.
* **Backend:** Python (FastAPI), Pandas (для обработки данных).
* **Storage:** SQLite / PostgreSQL или обработка CSV "на лету" через Pandas.

---

## 3. Архитектура проекта
1. **Data Layer:** Скрипты очистки и объединения CSV-файлов (Join по кодам).
2. **API Layer:** REST API (FastAPI) для передачи отфильтрованных данных в JSON.
3. **Client Layer:** Интерфейс с боковой панелью фильтров и областью конструктора.

---

## 4. Распределение ролей (Команда из 3 человек)

### Backend разработчик (Data & API)
1. **Парсинг:** Написание функций для чтения файлов РЧБ, Соглашений и ГЗ.
2. **Логика:** Реализация объединения таблиц по бюджетным кодам.
3. **API:** Создание эндпоинтов `/get_filters`, `/get_report` и `/export`.

### Frontend разработчик (UI & Logic)
1. **Скелет:** Развертывание React + Tailwind, настройка Sidebar и Layout.
2. **Компоненты:** Реализация динамических фильтров и таблицы данных.
3. **Интеграция:** Связка с API через Axios и визуализация графиков.

### Product / Design / Presentation
1. **UX/UI:** Отрисовка User Flow и интерфейса в Figma.
2. **Контент:** Сборка презентации и контроль соответствия ТЗ.
3. **Pitch:** Подготовка речи для защиты и демо-сценария.
