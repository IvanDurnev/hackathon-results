# 🧪 Руководство по тестированию мобильной версии

## Быстрый старт

### 1. Запуск проекта

```bash
cd frontend
npm install
npm run dev
```

Сайт будет доступен по адресу: `http://localhost:5173`

### 2. Открытие DevTools

**Chrome/Edge:**
- Нажмите `F12` или `Ctrl+Shift+I` (Windows/Linux)
- Нажмите `Cmd+Option+I` (Mac)

**Firefox:**
- Нажмите `F12` или `Ctrl+Shift+I` (Windows/Linux)
- Нажмите `Cmd+Option+I` (Mac)

### 3. Включение режима устройства

**Chrome/Edge:**
- Нажмите `Ctrl+Shift+M` (Windows/Linux)
- Нажмите `Cmd+Shift+M` (Mac)
- Или кликните на иконку 📱 в DevTools

**Firefox:**
- Нажмите `Ctrl+Shift+M` (Windows/Linux)
- Нажмите `Cmd+Option+M` (Mac)

## Тестирование на реальных устройствах

### Подключение по сети

1. **Узнайте IP адрес компьютера:**
   ```bash
   # Windows
   ipconfig
   
   # Mac/Linux
   ifconfig
   ```

2. **Запустите dev сервер:**
   ```bash
   npm run dev -- --host
   ```

3. **Откройте на мобильном:**
   ```
   http://[ваш-ip]:5173
   Например: http://192.168.1.100:5173
   ```

## Распространенные проблемы

### Проблема: Горизонтальная прокрутка страницы
**Решение:** Проверьте элементы с фиксированной шириной
```bash
# В DevTools Console
document.querySelectorAll('*').forEach(el => {
  if (el.scrollWidth > document.documentElement.clientWidth) {
    console.log(el);
  }
});
```

### Проблема: Текст слишком мелкий
**Решение:** Проверьте минимальные размеры шрифтов
- Mobile: минимум 12px
- Desktop: минимум 14px

### Проблема: Кнопки слишком маленькие
**Решение:** Минимальный размер touch target - 44x44px
```css
/* Проверьте padding кнопок */
button {
  min-height: 44px;
  min-width: 44px;
}
```

### Проблема: Меню не закрывается
**Решение:** Проверьте z-index overlay
```css
.overlay {
  z-index: 40;
}
.sidebar {
  z-index: 50;
}
```
