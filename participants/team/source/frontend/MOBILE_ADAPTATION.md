# Мобильная адаптация АМУР.БЮДЖЕТ

## Обзор изменений

Сайт полностью адаптирован под мобильные устройства с использованием responsive design подхода на базе Tailwind CSS.

## Основные изменения

### 1. Навигация и Layout

#### Sidebar (Боковая панель)
- **Desktop**: Фиксированная боковая панель слева (288px)
- **Mobile**: Скрыта по умолчанию, открывается через кнопку меню
- **Overlay**: Затемнение фона при открытии меню на мобильных
- **Закрытие**: Клик вне меню или на кнопку закрытия

#### Header (Шапка)
- **Desktop**: Полная высота 80px с заголовком и описанием
- **Mobile**: Адаптивная высота, кнопка меню слева
- **Текст**: Описание скрыто на маленьких экранах

### 2. Компоненты

#### MetricsGrid (Карточки метрик)
- **Desktop**: 3-4 колонки
- **Tablet**: 2 колонки
- **Mobile**: 1 колонка
- **Адаптация**: Уменьшенные отступы и размеры шрифтов
- **Числа**: `break-all` для длинных чисел

#### Таблицы
- **Горизонтальная прокрутка**: На мобильных устройствах
- **Минимальная ширина**: 600-800px для сохранения читаемости
- **Скрытие колонок**: Менее важные колонки скрыты на маленьких экранах
- **Адаптивные размеры**: Уменьшенные шрифты и отступы

#### Формы и фильтры
- **Grid**: Адаптивная сетка (1 колонка на mobile, 2-3 на desktop)
- **Кнопки**: Вертикальное расположение на мобильных
- **Input**: Адаптивные размеры padding и font-size

### 3. Страницы

#### Overview (Конструктор)
- Адаптивная сетка фильтров
- Вертикальное расположение кнопок на mobile
- Горизонтальная прокрутка таблицы
- Скрытие колонок "Бюджет" и "Период" на маленьких экранах
- Адаптивные детали контрактов и платежей

#### Analytics (Аналитика)
- Адаптивная сетка метрик (1-2-4 колонки)
- Уменьшенные графики на мобильных
- Вертикальное расположение круговой диаграммы и легенды
- Адаптивные размеры SVG графиков
- Оптимизированные прогресс-бары

#### ChatBot (AI Ассистент)
- Адаптивная высота заголовка
- Скрытие Session ID на маленьких экранах
- Уменьшенные размеры сообщений
- Адаптивные кнопки управления
- Горизонтальная прокрутка таблицы данных
- Сокращенные подсказки на mobile

### 4. Home страница

#### Hero секция
- Адаптивные размеры заголовков (3xl → 7xl)
- Вертикальное расположение кнопок на mobile
- Адаптивные отступы

#### Features
- 1 колонка на mobile, 2 на tablet, 3 на desktop
- Адаптивные размеры карточек

#### Stats
- 1 колонка на mobile, 3 на desktop
- Адаптивные размеры чисел

#### Preview
- Скрытие sidebar mockup на mobile
- Горизонтальная прокрутка таблицы
- Сокращенные значения для экономии места

## Breakpoints (Точки перелома)

```css
/* Tailwind CSS breakpoints */
sm: 640px   /* Маленькие планшеты */
md: 768px   /* Планшеты */
lg: 1024px  /* Маленькие ноутбуки */
xl: 1280px  /* Десктопы */
2xl: 1536px /* Большие экраны */
```

## Используемые техники

### 1. Responsive Grid
```jsx
className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-4 gap-3 sm:gap-4"
```

### 2. Адаптивные размеры
```jsx
className="text-xs sm:text-sm lg:text-base"
className="p-3 sm:p-4 lg:p-6"
```

### 3. Условное отображение
```jsx
className="hidden lg:block"        // Показать только на desktop
className="lg:hidden"              // Скрыть на desktop
className="hidden sm:table-cell"   // Показать в таблице на tablet+
```

### 4. Адаптивные отступы
```jsx
className="space-y-3 sm:space-y-4 lg:space-y-6"
className="gap-2 sm:gap-3 lg:gap-4"
```

### 5. Overflow handling
```jsx
className="overflow-x-auto -mx-4 sm:mx-0"  // Прокрутка с отрицательными отступами
className="min-w-[600px]"                   // Минимальная ширина для таблиц
```

## CSS улучшения

### index.css
- `-webkit-text-size-adjust: 100%` - предотвращение автомасштабирования на iOS
- `-webkit-overflow-scrolling: touch` - плавная прокрутка на iOS
- `-webkit-tap-highlight-color: transparent` - убирает подсветку при нажатии
- Адаптивные scrollbar стили

## Тестирование

1. **Mobile**: iPhone SE (375px), iPhone 12 Pro (390px), Samsung Galaxy S20 (360px)
2. **Tablet**: iPad (768px), iPad Pro (1024px)
3. **Desktop**: 1280px, 1920px

### Chrome DevTools
1. Открыть DevTools (F12)
2. Toggle device toolbar (Ctrl+Shift+M)
3. Выбрать устройство или задать custom размер
4. Тестировать все breakpoints

## Оптимизация производительности

1. **Lazy loading**: Изображения загружаются по мере необходимости
2. **Минимальный JavaScript**: Только необходимые компоненты
3. **CSS оптимизация**: Tailwind CSS purge удаляет неиспользуемые стили
4. **Touch events**: Оптимизированы для мобильных устройств

## Accessibility (Доступность)

1. **Touch targets**: Минимум 44x44px для кнопок
2. **Readable fonts**: Минимум 12px на мобильных
3. **Contrast**: Соответствие WCAG AA стандартам
4. **Focus states**: Видимые состояния фокуса для клавиатурной навигации

## Известные ограничения

1. **Таблицы**: Требуют горизонтальной прокрутки на очень маленьких экранах (<360px)
2. **Графики**: Упрощены на мобильных для лучшей читаемости
3. **Длинные тексты**: Обрезаются с ellipsis, полный текст в title атрибуте

## Будущие улучшения

1. **PWA**: Превращение в Progressive Web App
2. **Offline mode**: Кэширование данных для работы офлайн
3. **Touch gestures**: Свайпы для навигации
4. **Dark mode**: Темная тема для экономии батареи
5. **Landscape optimization**: Улучшенная поддержка альбомной ориентации
