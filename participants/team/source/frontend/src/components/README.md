# Структура компонентов

## pages/
Страницы приложения:
- `Overview.jsx` - Страница обзора с графиками и последними операциями
- `Constructor.jsx` - Страница конструктора выборок
- `Analytics.jsx` - Страница аналитики с детальными отчетами
- `Documents.jsx` - Страница управления документами

## dashboard/
Компоненты для основной рабочей области (дашборда):
- `Sidebar.jsx` - Боковое меню навигации
- `Header.jsx` - Верхняя панель с поиском и уведомлениями
- `MetricsGrid.jsx` - Сетка метрик (доходы, расходы, дефицит)
- `WorkspacePanel.jsx` - Основная рабочая область с фильтрами и таблицей
- `PreviewTable.jsx` - Таблица предварительного просмотра данных

## home/
Компоненты для лендинга/главной страницы:
- `Hero.jsx` - Главный баннер
- `Features.jsx` - Блок с возможностями системы
- `Stats.jsx` - Статистика
- `Preview.jsx` - Превью интерфейса

## ui/
Переиспользуемые UI компоненты:
- `Button.jsx` - Кнопка с вариантами (primary, secondary)
- `Input.jsx` - Текстовое поле ввода
- `Select.jsx` - Кастомный выпадающий список с анимацией
- `RadioGroup.jsx` - Группа радио-кнопок в стиле сайта

## icons/
Переиспользуемые SVG иконки:
- `HomeIcon` - Иконка главной страницы
- `MagicIcon` - Иконка конструктора (блоки)
- `ChartIcon` - Иконка аналитики
- `DocIcon` - Иконка документов
- `ChevronDownIcon` - Стрелка вниз для выпадающих списков

## constants/
Константы приложения:
- `dashboard.js` - Данные для дашборда (ссылки, метрики, справочники)

## data/
Mock данные:
- `mockData.js` - Тестовые данные для таблиц

## utils/
Утилиты:
- `cn.js` - Функция для объединения CSS классов

## Принципы организации:
- Компоненты сгруппированы по функциональным областям
- Каждый компонент отвечает за одну задачу
- Переиспользуемые UI компоненты вынесены в ui/
- Константы и данные отделены от компонентов
- Стили инлайновые через Tailwind CSS
- Нет дублирования кода
- Нет пустых файлов
