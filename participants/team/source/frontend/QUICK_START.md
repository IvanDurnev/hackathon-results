# 🚀 Быстрый старт - Мобильная версия

## Что было сделано?

Сайт **АМУР.БЮДЖЕТ** полностью адаптирован под мобильные устройства! 📱

## Как проверить?

### Вариант 1: Chrome DevTools (рекомендуется)

1. **Запустите проект:**
   ```bash
   cd frontend
   npm run dev
   ```

2. **Откройте в браузере:**
   ```
   http://localhost:5173
   ```

3. **Включите режим устройства:**
   - Нажмите `F12` (открыть DevTools)
   - Нажмите `Ctrl+Shift+M` (включить Device Mode)
   - Выберите устройство из списка или задайте размер вручную

4. **Протестируйте:**
   - Откройте мобильное меню (кнопка ☰)
   - Проверьте все страницы
   - Попробуйте разные размеры экрана

### Вариант 2: На реальном устройстве

1. **Узнайте IP адрес компьютера:**
   ```bash
   # Windows
   ipconfig
   
   # Mac/Linux
   ifconfig
   ```

2. **Запустите с доступом по сети:**
   ```bash
   npm run dev -- --host
   ```

3. **Откройте на телефоне:**
   ```
   http://[ваш-ip]:5173
   Например: http://192.168.1.100:5173
   ```

## Проблемы?

### Меню не открывается
- Проверьте, что экран < 1024px
- Обновите страницу (Ctrl+R)

### Таблица не прокручивается
- Это нормально на desktop (> 1024px)
- На mobile должна прокручиваться горизонтально

### Текст слишком мелкий
- Проверьте zoom браузера (должен быть 100%)
- Попробуйте другое устройство в DevTools
