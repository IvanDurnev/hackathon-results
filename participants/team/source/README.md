# AI-генератор презентаций «Амурский код 2026»

Проект разработан в рамках хакатона для кейса **Ростелеком**. Сервис позволяет автоматически трансформировать объемные документы (PDF/DOCX) в структурированные презентации формата PPTX, а так же генерировать презентации только описав их!

---

##  Технологический стек
*   **Backend:** Python 3.13, FastAPI (высокопроизводительный веб-фреймворк).
*   **AI Models:** 
    *   **Леопольд (Qwen 2.5 72B):** анализ текста, выделение тезисов и формирование структуры слайдов.
    *   **Yandex ART** генерация уникальных визуальных образов для слайдов.
*   **Frontend:** HTML5, CSS3 (фирменные цвета Ростелекома), Jinja2.
*   **Libraries:** `python-pptx` (сборка презентаций), `pypdf` / `python-docx` (парсинг документов).

---

## Функционал
-  **Умный парсинг:** извлечение смысла из загруженных файлов.
-  **Кастомизация:** выбор тона изложения (деловой, креативный) и количества слайдов.
-  **Генерация контента:** создание заголовков, текстов и описаний для нейросетевых изображений.
-  **Экспорт:** получение готового файла `.pptx`, доступного для редактирования.
---
## Как запустить проект

1. **Клонируйте репозиторий:**
   git clone https://github.com/Xaze-debug/Xakaton.git

2. **Установите зависимости:**
   pip install -r requirements.txt

3. **Настройте токены:**
   - Создайте файл `.env` в корневой папке.
   - Скопируйте содержимое `.env.example` в `.env` и вставьте свой `RT_API_TOKEN`.

4. **Запустите приложение:**
   python main.py
