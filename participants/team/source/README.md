# AI-генератор презентаций 

Инновационный сервис для автоматического создания презентаций (PPTX) из текстовых запросов или документов (PDF/DOCX) с использованием ИИ и интерактивным режимом ожидания.

## Фишки проекта
- **Интеллектуальный парсинг:** Извлечение ключевых смыслов из объемных документов.
- **Мульти-стиль:** Выбор стиля оформления (корпоративный, творческий и др.) и тона текста.
- **Генерация визуалов:** Каждый слайд получает уникальное изображение, созданное нейросетью Yandex ART.
- **Интерактив:** Пока ИИ генерирует слайды (3-4 минуты), пользователь может поиграть в классическую «Змейку» прямо в браузере.
- **Управление в игре:** Стрелочки или **WASD**.

## Технологии
- **Backend:** Python 3.13+, FastAPI.
- **AI Core:** Qwen 2.5 72B (структура) + Yandex ART (картинки).
- **Frontend:** HTML5, CSS3 (Glassmorphism), JavaScript (Canvas Game).
- **Libraries:** `python-pptx`, `pypdf`, `python-docx`, `python-dotenv`.

## Структура проекта
- `/output` — готовые презентации и артефакты (JSON структуры, изображения).
- `/static` — стили, логотипы Ростелекома и скрипты.
- `/templates` — HTML-шаблоны (главная со змейкой и страница предпросмотра).
- `main.py` — основной сервер приложения.
- `pptx_builder.py` — логика сборки финального файла.

## Как запустить (Quick Start)
1. **Клонирование:**
 Нужно клонировать репозиторий себе на компьютер
3. **Зависимости:**
 pip install -r requirements.txt
4. **Запуск:**
 python main.py
