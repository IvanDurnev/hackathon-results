# Rostel Presentation Generator

## Описание продукта

Это веб-приложение для генерации презентаций на основе текста и голосового запроса. Пользователь вводит тему, стиль и дополнительные параметры, получает структуру слайдов, редактирует данные и сохраняет готовую презентацию в PPTX. Приложение также поддерживает голосовой ввод, чтобы преобразовать устный запрос в текст.

## Стек

- Python 3.9
- Flask
- python-pptx
- PyMuPDF
- python-docx
- SpeechRecognition
- pydub
- requests
- python-dotenv
- HTML/CSS/JavaScript для фронтенда
- ffmpeg (системный инструмент для обработки аудио)

## Архитектура приложения

- `app.py` — основной серверный модуль Flask.
- `templates/` — HTML-шаблоны интерфейса.
- `static/` — статические ресурсы, включая сгенерированные изображения и презентации.
- `templates/previews/` — превью шаблонов презентаций.
- Backend:
  - Формирует структуру презентации через внешнее AI API.
  - Генерирует PPTX-файлы с заменой текстовых и графических шаблонов.
  - Обрабатывает голосовой ввод: принимает аудиофайл, конвертирует его в WAV с помощью pydub и распознает речь через SpeechRecognition.
- Frontend:
  - Пользовательский интерфейс ввода задачи, выбора параметров и управления слайдами.
  - Отправляет голосовые записи на сервер для распознавания речи.

## Локальное развертывание

1. Клонируйте репозиторий и перейдите в каталог проекта:

```bash
cd 'ваш католог проекта'
```

2. Создайте виртуальное окружение и активируйте его:

```bash
python3 -m venv venv
source venv/bin/activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Установите системный `ffmpeg` (обязательно):

```bash
brew install ffmpeg
```

5. Создайте файл `.env` при необходимости и задайте переменные окружения:

```bash
HACKATHON_API_TOKEN=ваш_токен
AI_BASE_URL=https://ai.rt.ru/api/1.0
LLM_URL=https://ai.rt.ru/api/1.0/llama/chat
IMAGE_GEN_URL=https://ai.rt.ru/api/1.0/ya/image
IMAGE_DOWNLOAD_URL=https://ai.rt.ru/api/1.0/download
PORT=5021
```

6. Запустите приложение:

```bash
PORT=5000 python3 app.py
```

7. Откройте в браузере:

```text
http://127.0.0.1:5000
```

## Примечания

- Убедитесь, что `ffmpeg` установлен и доступен в PATH.
- Если используется голосовой ввод, браузер может отправлять `audio/webm`, `audio/mp4` или `audio/aac`.
- Для корректной работы API генерации слайдов требуется рабочий AI API токен.
